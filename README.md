# cliptree

Clip lightweight tree statistics from stdin samples.

**Site:** https://theworker02.github.io/cliptree/

## Install / run

```bash
git clone https://github.com/theworker02/cliptree.git
cd cliptree
node src/cli.js
node --test
```
